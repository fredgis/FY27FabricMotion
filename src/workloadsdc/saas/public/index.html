The product

One score that everyone understands

GreenGrid blends renewable sourcing and energy efficiency into a single 0–100 green score and an A/B/C tier, with a clear next-best action for each site.

Transparent scoring

Green score = 60% renewable sourcing + 40% energy efficiency. No black box — the same formula your auditors and your engineers can both read.

A · B · C tiering

Every site lands in an actionable tier — A (75+), B (50–74), C (<50) — so leaders instantly see where to focus the next investment.

Portfolio rollups

Aggregate hundreds of sites into one portfolio view: average score, renewable mix, tier distribution, and best/worst performers.

Next-best action

Each site comes with a concrete tip — “increase renewable sourcing”, “improve efficiency”, or “on track” — turning data into a plan.

API-first

Everything is a REST call. Score a single site or a whole portfolio in one request — ready to embed in any app, BI tool or data workload.

Runs where your data lives

Point GreenGrid at your site data in Microsoft Fabric / OneLake and score it in place — no copies, no extract jobs.

How it works

From raw site data to a green score in three steps

1

Send your sites

POST a list of sites with their energyKwh and renewablePct to the GreenGrid API — directly from your app or your data platform.

2

We score them

GreenGrid runs the scoring algorithm and returns a green score, an A/B/C tier and a next-best action per site.

3

Act on the portfolio

Get a portfolio rollup — average score, renewable mix, best & worst sites — to drive your sustainability decisions.

For developers

The algorithm, exposed as a clean API

GreenGrid is API-first: the scoring engine that powers our product is the same one your applications and Microsoft Fabric data workloads call at runtime. One key, two endpoints.

  • Stateless & deterministic — same input, same score, every time.
  • Simple x-api-key auth, permissive CORS for embedded apps.
  • Scores a single site or a whole portfolio in one request.
GET /health POST /score
POST /score
# Score a portfolio of sites
curl -X POST https://api.greengrid.io/score \
  -H "Content-Type: application/json" \
  -H "x-api-key: greengrid-demo-key" \
  -d '{
    "sites": [
      { "siteId": "site-hel", "name": "Helsinki DC",
        "city": "Helsinki", "energyKwh": 320, "renewablePct": 88 }
    ]
  }'

# → response
{
  "sites": [
    { "name": "Helsinki DC", "greenScore": 80,
      "tier": "A", "tip": "On track" }
  ],
  "summary": { "avgScore": 80, "tierCounts": { "A": 1 } }
}
